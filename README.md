# social_media_page_analysis

## Тестовое задание:

Возьмите страницу любой медийной персоны, которая вам нравится, в любой социальной сети и проведите анализ, что больше всего влияет на реакцию аудитории (комментарии, лайки и репосты). 

Например: время суток публикации, день недели, промежуток между постами или наличие каких-то ключевых слов.

В качестве ответа приложите два файла:
- письмо этому человеку, которое вы бы написали, если бы хотели поделиться результатами этого анализа;
- исходный код (если делали в основном вручную) или выгрузку диалога с нейросетью (если делали в основном через нее).
